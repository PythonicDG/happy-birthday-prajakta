# 📸 Add photos here

Upload: https://github.com/PythonicDG/happy-birthday-prajakta/upload/main/photos

- The **file name becomes the caption**: `01 Our first trip.jpg` → "Our first trip"
- Numbers at the start set the order (01, 02, 03 …)
- Any size is fine, including iPhone HEIC photos. They're resized automatically.
- The site updates about 1 minute after you click **Commit changes**.
- To remove a photo, open it here on GitHub → ⋯ → Delete file.
